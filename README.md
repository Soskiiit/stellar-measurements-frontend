### Описание

**Тема** - Определение расстояния до звезды в Млечном пути по ее годовому параллаксу; \
**Услуги** - звезды; \
**Заявка** - расчет расстояния с указанием параллакса по каждой.

## Страницы приложения

Приложение состоит из четырёх страниц: **лента звёзд** (главная), **каталог звёзд** («плитка»), **добавление звезды** и **авторизация**. Описание составлено по шаблонам бэкенда (ветка `database-adminer-orm`), страница авторизации — по API ветки `jwt-authentication`.

### Общие элементы всех страниц

**Шапка:**
- **Логотип-кнопка «⭗ StarParallax»** — возврат на главную страницу (ленту).

**Нижняя навигационная панель** — 4 пункта, активный пункт подсвечен:

| Пункт | Назначение |
|---|---|
| **Лента** | переход к ленте звёзд (`/`) |
| **Добавить** | переход к форме добавления звезды (`/add_parallax_star`) |
| **Каталог** | переход к каталогу-плитке (`/parallax_stars_catalog`) |
| **Вход** | переход к странице авторизации |

---

### 1. Лента звёзд (главная страница)

Полноэкранная карточка одной звезды с фоновым видео.

**Поля и элементы:**
- **Фоновое видео звезды** — автоматическое циклическое воспроизведение без звука; при отсутствии видео показывается фото звезды.
- **Название звезды** — заголовок карточки.
- **Описание звезды** — краткая астрономическая справка (если задана).
- **«Параллакс: X.XXX"»** — годовой параллакс звезды в секундах дуги.
- **«Расстояние: X.XX пк»** — расстояние до звезды в парсеках.
- **Счётчик лайков** — иконка ♡ и количество отметок «мне нравится».

**Кнопки:**
- **«Следующая» (стрелка вниз)** — циклическое переключение на следующую звезду ленты.
- **«больше ▼ / меньше ▲»** — раскрыть / скрыть полный текст описания звезды.
- Нижняя навигационная панель и логотип в шапке.

---

### 2. Каталог звёзд («плитка»)

Сетка карточек опубликованных звёзд с фильтром по расстоянию.

**Поля и элементы:**
- **Заголовок «Каталог звёзд»**.
- **Фильтр «Расстояние до, пк»** — ползунок выбора максимального расстояния: от 0 до 1000 пк с шагом 1 пк (по умолчанию 1000), граничные метки шкалы `0` и `1000`.
- **Карточка звезды**, для каждой звезды:
  - фото звезды (при отсутствии или ошибке загрузки подставляется дефолтное изображение);
  - название звезды;
  - расстояние **«D = X.XX пк»**;
  - счётчик лайков (♡ и количество).

**Кнопки:**
- **«Поиск»** — применить значение фильтра и показать звёзды не дальше выбранного расстояния.
- **Карточка звезды** — клик открывает ленту, начиная с выбранной звезды.
- **«✕» (Удалить услугу)** на каждой карточке — удалить звезду из каталога.
- Нижняя навигационная панель и логотип в шапке.

---

### 3. Добавление звезды

Двухшаговый сценарий: сначала создаётся черновик, затем он публикуется.

#### Шаг 1 — «Новая звезда»

**Поля:**
- Раздел **«Медиа»**:
  - **«Видео звезды»** — выбор видеофайла (`video/*`), до выбора показывается дефолтное видео;
  - **«Фото звезды»** — выбор изображения (`image/*`), до выбора показывается дефолтное фото.
- **«Название звезды»** — текстовое поле, обязательное, до 100 символов (плейсхолдер: «Например: Сириус»).

**Кнопки:**
- **«Далее»** — создать черновик и перейти к шагу 2.

#### Шаг 2 — «Публикация черновика»

**Поля:**
- Раздел **«Медиа»** — превью загруженных видео и фото звезды.
- **«Название звезды»** — текстовое поле, только чтение (значение из черновика).
- **«Краткое описание»** — многострочное поле, обязательное, до 255 символов (спектральный класс, созвездие и т.п.).
- **«Годичный параллакс, мас»** — числовое поле, обязательное, от 0.001 до 9.999 с шагом 0.001 (плейсхолдер: `0.379`).
- **«Расстояние, пк»** — числовое поле, обязательное, от 0.01 до 999.99 с шагом 0.01 (плейсхолдер: `2.64`).

**Кнопки:**
- **«Опубликовать»** — опубликовать звезду и перейти в каталог.

### 4. Авторизация

Страница открывается по кнопке **«Вход»** — четвёртому пункту нижней навигационной панели.

**Поля:**
- **«Логин»** (`login`) — текстовое поле, обязательное, до 50 символов.
- **«Пароль»** (`password`) — поле пароля, обязательное.

**Кнопки:**
- **«Войти»** — аутентификация (`POST /api/users/login`): при успехе выдаётся JWT-токен (HTTP-only cookie, срок действия 24 часа).
- **«Зарегистрироваться»** — регистрация (`POST /api/users/register`): создаётся пользователь с ролью создателя услуг (Astronomer).
- **«Выйти»** — деавторизация (`POST /api/users/logout`): токен отзывается (заносится в чёрный список) и cookie очищаются.
