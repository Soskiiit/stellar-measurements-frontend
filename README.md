# Stellar Measurements Frontend (StarParallax)

Репозиторий фронтенд-приложения по дисциплине «Проектирование систем и продуктовая веб-разработка».

- **Тема:** Определение расстояния до звезды в Млечном пути по ее годовому параллаксу
- **Услуги:** Звёзды (`parallax_stars`)
- **Заявка:** Расчёт расстояния с указанием параллакса по каждой

---

## Описание страниц приложения, кнопок и полей

### 1. Навигационная панель (`NavigationBar`)
Расположена в нижней части экрана на всех страницах и состоит из **4 пунктов**:
1. **Кнопка «Лента»** — доступна для гостя. Переключает интерфейс на просмотр ленты звёзд.
2. **Кнопка «Добавить»** — заблокирована (`disabled`) для гостя. Предназначена для авторизованного создателя.
3. **Кнопка «Каталог»** — доступна для гостя. Переключает интерфейс на плитку карточек звёзд.
4. **Кнопка «Вход»** — заблокирована (`disabled`) для гостя.

---

### 2. Страница каталога звёзд (Плитка)

#### Поля:
- **Ползунок фильтрации расстояния (`Form.Range`)**: выбор максимального расстояния до звезды в парсеках (от 0 до 1000+ пк).
- **Индикатор текущего значения фильтра**: отображение выбранного расстояния (`D пк`).
- **Текстовые метки шкалы**: граничные значения диапазона (`0 пк`, `1000 пк`).
- **Поля карточки звезды**:
  - Изображение звезды (с автоматической подстановкой дефолтной картинки при отсутствии или ошибке загрузки).
  - Название звезды (`name`).
  - Расстояние до звезды в парсеках (`D = X.XX пк`).
  - Счётчик лайков звезды.

#### Кнопки:
- **Кнопка «Поиск»**: применяет введённое в ползунке значение и фильтрует список карточек.
- **Карточка звезды**: кликабельный элемент, осуществляет переход на страницу «Лента», начиная с выбранной звезды.
- **Логотип «⭗ StarParallax» в шапке**: осуществляет возврат на главную страницу каталога.

---

### 3. Страница ленты звёзд

#### Поля:
- **Фоновое вертикальное видео звезды**: автоматическое циклическое воспроизведение видеоролика (с дефолтным видео при отсутствии/ошибке).
- **Название звезды**: заголовок карточки в оверлее.
- **Описание звезды**: краткая астрономическая справка о звезде.
- **Поле «Параллакс»**: годовой параллакс звезды в секундах дуги (`X.XXX"`).
- **Поле «Расстояние»**: расстояние до звезды в парсеках (`X.XX пк`).
- **Счётчик лайков**: количество отметок «мне нравится» у текущей звезды.

#### Кнопки:
- **Кнопка «Следующая» (стрелка вниз)**: циклическое переключение на следующую звезду в ленте.
- **Кнопка «больше ▼ / меньше ▲»**: раскрывает и скрывает полный текст описания звезды.
- **Логотип «⭗ StarParallax» в шапке**: осуществляет возврат в каталог.
